# Module: evaluator
**Role:** Parses and evaluates MUGEN CNS trigger/expression strings — the raw `Controller.Triggers`/`Controller.Parameters` strings `character/cns` deliberately leaves unevaluated — against a fighter's live runtime state, returning a loosely-typed (bool/int/float) result or a descriptive error. `Evaluate` memoizes `Parse` by source string in a package-level `parseCache` map, so a controller's trigger/parameter string checked every simulation tick is only lexed/parsed once per distinct string, not once per call — safe unsynchronized given this engine's single-threaded, no-goroutines target (see `.vibe/decisions/009-011`).
**Files:** `evaluator/lexer.go`, `evaluator/ast.go`, `evaluator/parser.go`, `evaluator/context.go`, `evaluator/eval.go`, `evaluator/triggers.go`, `evaluator/constants.go`, `evaluator/animation.go`, `evaluator/opponent.go`, `evaluator/attr.go`
**Grammar:** Ikemen GO's expression compiler (compiler.go, commit 54d4148a): precedence lowest to highest `||`, `^^`, `&&`, `|`, `^`, `&`, `=`/`!=`, `<`/`>`/`<=`/`>=`, `+`/`-`, `*`/`/`/`%`, `**` (left-associative), prefix `!`/`-`/`~`. After `=`/`!=` an interval `[a, b]`, `[a, b)`, `(a, b]`, `(a, b)` with expression bounds (`intervalNode`; a `(` without a comma is a parenthesized operand); after `AnimElem = n,` an interval with integer bounds. Int typing as Ikemen GO: `/` and `**` stay ints between ints (`**` float when the exponent is negative), `%` and the bitwise operators work on int32. `Cond(c, a, b)` evaluates only the branch it picks; `IfElse` evaluates all three. Not reproduced: CNS postfix `!` (expPostNot under ignoreMostErrors), Ikemen GO's undefined value (division by zero is an error here).
