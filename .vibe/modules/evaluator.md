# Module: evaluator
**Role:** Parses and evaluates MUGEN CNS trigger/expression strings — the raw `Controller.Triggers`/`Controller.Parameters` strings `character/cns` deliberately leaves unevaluated — against a fighter's live runtime state, returning a loosely-typed (bool/int/float) result or a descriptive error. `Evaluate` memoizes `Parse` by source string in a package-level `parseCache` map, so a controller's trigger/parameter string checked every simulation tick is only lexed/parsed once per distinct string, not once per call — safe unsynchronized given this engine's single-threaded, no-goroutines target (see `.vibe/decisions/009-011`).
**Files:** `evaluator/lexer.go`, `evaluator/ast.go`, `evaluator/parser.go`, `evaluator/context.go`, `evaluator/eval.go`, `evaluator/triggers.go`, `evaluator/constants.go`, `evaluator/animation.go`
**Exports:** `Parse(expr string) (*Expression, error)`, `(*Expression).Eval(ctx Context) (Value, error)`, `Evaluate(expr string, ctx Context) (Value, error)`, `Context` (embeds `match.FighterState`; adds `Time`, `Ctrl`, `Anim`, `AnimTime`, `Vars [60]int`, `SysVars [5]int`, `FVars [40]float32`, `SysFVars [5]float32`, `Consts *Constants`, `Anims map[int]air.Animation` (the character's animations by number, set once by `NewRuntime`, read by `AnimElem`/`AnimElemTime`/`AnimElemNo`/`AnimExist`/`SelfAnimExist`, see `.vibe/decisions/026`), `PalNo int` (0 reads as 1), `ActiveCommands map[string]bool`, `Sounds []SoundEvent` -- a per-tick event log `statemachine.Step` clears to `nil` on every call, not persistent fighter state like the fields before it, see `.vibe/decisions/017`), `Locals LocalFrame{Names []string; Values []Value}` (the `$name` frame zssexec passes in; unassigned slots read 0), `ZSS bool` (set by zssexec: `EvaluateMut` then short-circuits), `Persistent [MaxPersistent]int32` (the `.zss` `persistent(N)` counters, `MaxPersistent = 16`, owned by zssexec), the `:=` operator (assigns `var`/`sysvar` inside any expression, via `EvalMut`; locals are read-only), `SoundEvent{Group, Sample int}` (one `PlaySnd` controller execution, addressing a sound the same way `character.Sound` itself is keyed), `Constants` (`ParseConstants(io.Reader)`, `Lookup(name) Value`: a character's `[Data]/[Size]/[Velocity]/[Movement]/[Constants]` over Ikemen GO's defaults, read by `Const(name)`; unknown name reads int 0; nil reads the defaults; shared with item 043 physics, see `.vibe/decisions/025`), `(*Context).AssignVar(target, idx, v)` (the one place `var`/`sysvar`/`fvar`/`sysfvar` are stored, for `:=` and `VarSet`), `ElementAt(anim, animTime) (elem, elapsed)` (the element playing and the ticks spent in it, shared with the root package's `currentFrame`), `Value` (`Kind` + `Number float64`, with `Bool()`/`Float()`/`Int()`), `Kind` (`KindBool`, `KindInt`, `KindFloat`)
**Depends on:** `modules/match.md` (embeds `match.FighterState` in `Context`)
