# Module: statemachine
**Role:** Drives a fighter's state transitions by interpreting `character/cns`'s `StateDef`/`Controller` data with `engine/evaluator`, one simulation tick at a time. `PowerAdd` evaluates its `value` parameter, adds it to `Context.Power`, and clamps the result to `[0, DefaultMaxPower]` (a hardcoded `3000`, MUGEN's own default cap — `engine` has no lifebar/system-config data to override it with yet, see `.vibe/decisions/015`).
**Files:** `statemachine/statemachine.go`
**Exports:** `Step(ctx evaluator.Context, states map[int]cns.StateDef) (Result, error)`, `Result{Context evaluator.Context, Applied []int}`, `ApplyController(ctrl cns.Controller, ctx *evaluator.Context, exists func(int) bool) (bool, error)`, `ControllerTypeChangeState`/`ControllerTypeVarSet`/`ControllerTypeHitDef`/`ControllerTypePowerAdd` (string constants — the single source of truth for controller-type names other packages, e.g. the root `engine` package's own `HitDef` classification in `tick.go`, need to recognize), `DefaultMaxPower` (int constant, 3000)
**Depends on:** `modules/evaluator.md`, `modules/match.md` (via `evaluator.Context`), `character/cns` (external module, `StateDef`/`Controller` — read-only)
**Depended on by:** `modules/zssexec.md` (reuses `ApplyController` to apply `.zss` controller-shaped statements)
