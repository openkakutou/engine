# Module: zssexec
**Role:** Executes `character/zss`'s parsed Statedef/Function `.zss` script bodies against a fighter's live `evaluator.Context` -- the `.zss` counterpart to `statemachine.Step` for `.cns`-driven state execution. `Compile` precomputes a script's Statedef/Function blocks into two lookup maps (by state number, by function name) once, so `Step`'s internal `findStatedef`/`findFunction`-shaped lookups are O(1) instead of rescanning the script's blocks on every call -- first-occurrence-wins on a duplicate state number/function name. See `.vibe/decisions/013`.
**Files:** `zssexec/zssexec.go`, `zssexec/parser.go`
**Exports:** `Compile(script zss.Script) CompiledScript` (parses every block once), `CompiledScript` (with `Errors() []error`, one per block that does not parse, naming the block and the text, and `Header(number) (cns.StateDef, bool)`, a Statedef header converted to the `cns.StateDef` the root package's `enterState` takes -- literal values only, an expression-valued field stays zero), `Step(ctx evaluator.Context, prog CompiledScript) (Result, error)` (the current state, targets checked against the script's own Statedefs), `StepState(ctx, number, prog, exists func(int) bool) (Result, error)` (any state number, `exists` checks ChangeState targets over the caller's whole merged table: how `Tick` runs -3/-2/-1 and the current state), `StepStateDuringHitPause(ctx, number, prog, exists)` (same, as Ikemen GO's `StateBlock.Run` runs a hit pause), `Result{Context, Sounds, Unsupported, SkippedCalls}`
**Depends on:** `modules/evaluator.md` (condition evaluation), `modules/statemachine.md` (reuses `ApplyController` for controller-shaped statements), `character/zss` (external module, `Script`/`Block` -- read-only), `character/cns` (external module, `Controller` -- a `ctrlStmt` wraps one, read-only)

**Grammar (decision 022):** `parser.go` is a statement scanner over the whole body text, newline-insensitive, mirroring Ikemen GO's `stateBlock`/`subBlock`/`letAssign`/`callFunc` (`src/compiler.go`, commit `54d4148a`). A statement ends at `;`, `{` or `}` outside strings and brackets; `#` comments are stripped. Forms: `[ignoreHitPause] [persistent(N)] if COND {...}` with `else if`/`else`, the same attributes before a bare `{...}`, `let a, b = e1, e2;`, `let a, b = call F(args);`, `call F(args);`, `name{key: value; ...}` (values may span lines and hold commas), and `EXPR;` which must contain `:=` (else "Expression with unused value", as in Ikemen GO). `for`/`while`/`switch` return "not supported yet". `ignoreHitPause` is recorded with Ikemen GO's inheritance (every block of a Function has it) and acted on by `StepStateDuringHitPause` (decision 024).
**Locals:** one flat slot table per Statedef/Function (a Function's is arguments, return values, then lets; names are not block-scoped). Each call gets a fresh zeroed frame on the package-level growable `localStack`; return values are copied back only if the call did not change state. `Step` sets `Context.Locals` per frame and leaves it empty on return. Parse time checks every `$name` is declared (a text scan, because the parser must accept expressions the evaluator cannot parse yet).
**Persistent:** `persistent(N)` counters live in `Context.Persistent` (16 per Statedef, error at parse beyond; not allowed in a Function or a negative state); semantics of `StateBlock.Run` (N <= 0: once per state entry); zeroed by `Step` when a state change applies.
**Hit pause (decision 024):** `StepStateDuringHitPause` follows `StateBlock.Run` (`bytecode.go:5136-5260`): a block not flagged ignoreHitPause does nothing (no condition evaluated, its persistent counter untouched); the statements directly in a block (controllers, `let`, assignments, `call`) run only when the block's `ctrlsIgnoreHitPause` holds, so a Statedef's top level never runs but `ignoreHitPause{...}` blocks do; a Function body runs whole once called. `Compile` ignores a Statedef whose number is symbolic or relative (`NumberRaw`): it has no number to index under.
**Result:** `Result.Sounds` is the call's `PlaySnd` events (nil in the returned Context). `Result.SkippedCalls` lists calls skipped for an undefined function or a wrong argument/return count (Ikemen GO logs and runs on). `Step` sets `Context.ZSS` while running so `evaluator.EvaluateMut` short-circuits `&&`/`||` in controller parameters as Ikemen's .zss compiler does; it is false in the returned Context. `_` as a Function parameter takes a slot but cannot be read. The persistent counters are zeroed by `statemachine.applyChangeState` and the root `enterState`, not by zssexec.
